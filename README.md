# 나리키리 던전 2 — FFR 통합 한국어 패치 v0.9

기존 FFR 한글판에 EEPROM 저장 복구, 달무리 8×8 글꼴, 이름·메뉴 번역과 표시 수정을 함께 적용하는 **공개 검증판**입니다. 지원하는 FFR 원본에 누적 BPS 하나를 적용합니다.

![나리키리 던전 2 프로젝트 식별 이미지](logo.png)

`logo.png`는 사용자가 저장소 식별용으로 제출하고 사용을 요청한 이미지입니다. 공식 로고나 원 게임 권리자의 승인·제휴를 뜻하지 않으며, 코드·문서의 MIT 라이선스와 글꼴의 Apache-2.0 라이선스가 이 이미지에 적용되지는 않습니다. 파일 정보와 권리 경계는 [RIGHTS.md](RIGHTS.md)에 기록합니다.

기본 이름은 **훌리오 / 캐로**입니다. 사용자가 제공한 나무위키 인물·코스튬 표를 기준으로 목록·상세·선택 화면과 해당 대사의 이름을 맞췄습니다. 표 내부의 셀시우스/세르시우스 충돌은 인물 제목인 셀시우스를 채택했습니다.

## 적용

[Releases](https://github.com/GimoXagros/narikiri2-save-compat/releases)의 `NARIKIRI2_AN9J_K_DALMOORI_v0.9_FFR_PACKAGE.zip`을 풀고 Python 3.10 이상으로 실행합니다. 패치 적용에는 추가 Python 패키지가 필요하지 않습니다.

```powershell
python apply_ffr_v09.py "최초_FFR.gba" --output "NARIKIRI2_AN9J_K_DALMOORI_v0.9.gba"
```

입력은 아래 FFR 파일과 정확히 일치해야 합니다. 이미 수정한 ROM에 덧붙이지 마십시오. 출력은 새 파일로 생성되며 기존 파일을 덮어쓰지 않습니다.

| 파일 | 바이트 | SHA-256 |
| --- | ---: | --- |
| FFR 입력 | 12,582,912 | `f94cb5a128c8a98e6e18e6a0598ebf9b266f54da0750367af8defac3eb2df7d4` |
| v0.9 결과 | 12,713,984 | `560535ba5dce7246a4c1b210a082b93a08091b8f9e2bfa96467e44adbbf65c81` |
| FFR BPS | 145,379 | `38cba8fbf0fee41af02859df1a607eda2dbedee17f37afbb05fac05316449866` |

## 변경과 검증

- Candidate A의 79바이트 EEPROM/8 KiB 저장 복구 유지.
- 512개 완성형 글리프의 두 뱅크와 기존 소형 글꼴의 문자 셀 217개를 달무리 원본 생성기로 제작. 기능 셀 39개, 기존 대형 글꼴과 음성·음악 자산 보존.
- 아이템 157개, 직업 201개, 몬스터 165개, 기술 232개 등 소형 문자열 1,413필드와 대형 이름 435필드 검증. 사용자 코스튬 200종은 3개 표시 경로에서 대조.
- 노란 덧칠처럼 보이던 VRAM 압축 해제 오류, 전투 이름 잘림으로 인한 정지, 주문 사용 후 글자 덮어쓰기를 수정.
- 이름 입력, 상점·정보, 타이틀 선택, 전투 명령·일시정지·표적·결과의 확인된 24개 글자 그룹 수정.
- mGBA에서 새 게임 저장/두 차례 재실행, 6칸 혼합 이름, 기존 세이브 재저장, 중단 저장의 1회 재개, 첫 숲 전투의 주문·메뉴·승리·필드 복귀 확인.

도감·아이템의 넓은 표시 검사는 독립된 RAM 시험 상태로 수행했습니다. 자연 해금이나 전편 플레이 완료를 뜻하지 않습니다. 자세한 범위와 수치는 [VERIFICATION.md](VERIFICATION.md)에 있습니다.

## 세이브

기존 Candidate A의 8 KiB 게임 내 저장을 사용하십시오. ROM과 저장 파일의 기본 이름·위치는 실행기에 맞춰야 합니다. 새 ROM에서는 기존 savestate 대신 게임의 이어하기로 불러오십시오. 수정 전 VBA-M의 32 KiB 저장은 별도 형식 판정이 필요합니다. 도구는 사용자의 저장 파일을 자동 변경하지 않습니다.

기존에 직접 정한 이름은 유지됩니다. 기본 이름 변경은 새 게임부터 적용됩니다.

## 공개 범위

ROM·세이브·BIOS·전체 추출 대본은 공개하지 않습니다. 로컬 결과 ROM은 사용자가 준비한 FFR로 생성합니다. 신규 도구·문서는 MIT, 달무리 글꼴은 Apache-2.0입니다. [RIGHTS.md](RIGHTS.md), [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)를 함께 확인하십시오.

v0.9는 공개 검증판입니다. 최종 ROM의 실기 시험과 장시간 전체 진행 검증 후 v1.0으로 승격합니다. 달무리 영문·숫자는 원래 4픽셀 폭을 유지하므로 기존 8픽셀 셀 안의 간격이 달라 보입니다.
