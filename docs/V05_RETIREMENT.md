# v0.5 배포 중단 — BETA3 전환에 따른 안내

2026-09-07부터 현재 배포 기준은 **BETA3(071102) 기반 v0.9b**입니다. 이 BETA3의 `0xA601C..0xA6800` 저장 영역은 일본어 원본의 EEPROM 구현과 바이트 단위로 일치합니다. v0.9b도 이를 그대로 보존하며 새 저장·이어하기·재저장 시험을 통과했습니다. **BETA3에 v0.5 저장 복구를 적용할 필요가 없습니다.**

사용자 요청에 따라 GitHub의 v0.5 릴리즈는 배포 중단 표시와 함께 초안으로 전환합니다. 릴리즈를 삭제하지 않으며 태그·소스 이력·기존 파일의 백업은 보존합니다. 기존 v0.9/v0.9a 파일은 교체하지 않습니다.

이 판단은 BETA2 저장 복구가 무의미했다는 뜻이 아닙니다. 최초 FFR BETA2에는 다른 저장 코드가 있었으며 v0.5가 복원했던 79바이트는 해당 버전에 필요한 변경이었습니다. v0.9/v0.9a에는 그 복구가 이미 포함돼 있습니다. BETA2를 계속 쓰는 사람은 자신의 ROM 해시와 버전에 맞는 기존 기록을 확인해야 합니다.

| 사용 중인 ROM | 저장 복구 취급 |
| --- | --- |
| 수정하지 않은 FFR BETA3(071102) | 별도 v0.5 복구 불필요. v0.9b는 이 원본에 직접 적용 |
| v0.9b | BETA3 저장 코드 유지. 복구 도구를 덧붙이지 않음 |
| 최초 FFR BETA2 | 원래 저장 문제는 별개로 존재. BETA3용 패치 입력으로 사용할 수 없음 |
| BETA2 기반 Candidate A/v0.9/v0.9a | 저장 복구가 이미 포함됨 |

버전별 입력 해시는 config/source_profiles.json에 있습니다. 일반 8 KiB 게임 내 저장과 savestate·32 KiB 형식 문제는 구별해야 하며, v0.9b 적용 도구는 개인 저장 파일을 변환하거나 덮어쓰지 않습니다.
