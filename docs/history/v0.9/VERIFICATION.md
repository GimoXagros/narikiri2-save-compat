## mGBA 실행

코어 `0.11-219-e31759b`, SHA-256 `0d3177c927d791fef897f735d88db3646f7932d02054af108619c6df4e1597f1`.

새 게임에서 훌리오/캐로를 확인하고 저장 → 프로세스 재시작/불러오기 → 아이템 구매·재저장 → 재시작/불러오기까지 확인했습니다. 훌리오BBB/캐로라는 6칸 혼합 입력에도 같은 저장 경로를 시험했습니다. 중단 저장은 광산 입구로 재개되고, 소비 후 재시작하면 중단부터 항목이 사라졌습니다. 기존 8 KiB 저장의 이름과 진행을 불러와 재저장한 뒤 다시 읽었습니다. 이 경로들에는 RAM 수정이 없습니다.

첫 숲 전투는 15,308프레임의 실제 입력을 재생하여 명령/기술/도구/대열 메뉴, 주문, 승리 결과와 필드 복귀를 확인했습니다. 주문 이후 29개 캡처의 표시 글리프가 원래 달무리 비트맵과 일치했습니다. 자연 전투에서 사용 가능한 회복 아이템의 소비까지 검증했다는 주장은 하지 않습니다.

독립된 RAM 시험 상태로 아이템 156개(실제 아이템, 없음 제외), 도감 코스튬 200개, 몬스터 142개, 인물 22개의 목록과 상세를 열었습니다. 코스튬 상세에 연결된 기술명 224개를 실제 화면에서 확인했습니다. 나머지 8개 기술 테이블 항목은 정적 검사 범위이며 미사용이라고 단정하지 않습니다. 이 시험은 자연 해금 검증이 아닙니다.

노란 배경 문제는 GBA VRAM용 압축 해제에서 거리 1 참조가 이전 반워드를 읽는 원인으로 재현했습니다. 거리 2 이상 압축과 4바이트 정렬을 적용하고 실제 아이템 메뉴 재로딩에서 잔여 덧칠이 없어짐을 확인했습니다.

24개 확인된 UI 글자 그룹을 수정했습니다. 이름 편집 3종·빈 동료 표시·상점·정보·타이틀 4종·전투 명령 4종·일시정지/표적·결과 8종입니다. 승리 화면의 보너스/갈드/경험치/연타는 자연 전투에서 확인했고, 레벨/상승/기술/상승은 원래 OAM 배치를 해석한 독립 픽셀 검사로 검증했습니다. 모든 미관찰 이미지 자원의 완전 번역을 주장하지 않습니다.

## 남은 범위

v0.9는 공개 검증판입니다. 최종 파일의 실기 시험과 장시간 전체 진행은 v1.0 승격 조건입니다. 과거 Candidate A의 GBARunner3 성공은 최종 ROM 실기 검증을 대체하지 않습니다.

정적 텍스트 검사는 전체 대사의 문학적 재번역이나 모든 동적 분기 실행을 증명하지 않습니다. 원래 로고·저작권 그림·미분류 미관찰 자원은 보존합니다. 달무리 영문·숫자의 원래 4픽셀 폭을 유지하므로 8픽셀 셀에서 간격이 넓어 보입니다.
