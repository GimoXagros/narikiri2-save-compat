# v0.9a — 공개 검증판

## 수정

전투 중 스펙터클즈와 인스펙트 아이를 사용했을 때 적 정보가 테두리 모양 문자로 깨지던 문제를 수정했습니다. 해당 정보창이 사용하는 별도 글꼴 경로에서 한글을 그리며, HP 숫자와 속성 아이콘은 보존합니다. 정보창을 닫은 뒤 전투가 계속 진행되는 것도 확인했습니다.

8,038개 고유 문자열을 개별 검토하여 5,186개를 교정했습니다. 등장인물·직업·지역·아이템 등의 표기를 대사와 맞추고, 띄어쓰기·맞춤법·문맥상 오역을 다듬었습니다. 필리아를 휘리아로, 훈다크르를 운다클로, 나리키리사를 변신술사로 부르던 불일치를 수정했습니다. 원문에 없는 등장인물이나 설정으로 바꾸지 않았으며, 수치와 제어 코드도 보존합니다. 원문 ‘一の狩り場’를 ‘제１ 사냥터’로 쓰는 두 곳은 숫자 표기 변경으로 별도 기록했습니다.

아이템 설명 9곳이 두 줄 표시창의 폭을 넘던 문제를 고쳤습니다. 우드로우·셀시우스 루트 설명의 첫 줄이 사라지던 현상도 여기에 포함됩니다. 저장 위치의 짧은 제목이 장소 이름과 겹치던 부분은 ‘위치’로 정리했습니다.

v0.9의 저장 복구, 기본 이름 훌리오/캐로, 달무리 글꼴과 노란 덧칠 현상·전투 표시 수정은 유지합니다.

도감의 본명 표기를 **레이시스 포말하우트**로 교정했습니다. 통칭 레이스와 본명 레이시스를 구분하는 원래 대사는 유지합니다.

## 적용 및 범위

최초 FFR 원본에 v0.9a 누적 BPS 하나를 적용합니다. v0.9 ROM에 중복 적용하지 마십시오. 기존 8 KiB 게임 내 저장을 사용할 수 있으며, 직접 입력한 이름을 강제로 바꾸지 않습니다.

공개 검증판입니다. 전체 대본 대조와 실제 모든 분기 플레이 완료는 구분합니다. mGBA에서 저장·이름·전투와 표시 경로를 확인했으며, 도감·아이템 일괄 검사는 독립된 RAM 시험 상태를 사용했습니다. 실기 및 장시간 전체 진행은 v1.0의 추가 검증 조건입니다. 자세한 증거와 분모는 [VERIFICATION.md](VERIFICATION.md)에 있습니다.

이전 릴리즈 기록은 [v0.9](docs/history/v0.9/RELEASE_NOTES.md)에 보존합니다.
