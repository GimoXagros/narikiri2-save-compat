# 나리키리 던전 2 — FFR 통합 한국어 패치 v0.9a

대사 고유명사와 문장을 교정하고, 전투 중 적 정보창의 글자 깨짐을 수정한 **공개 검증판**입니다. v0.9의 EEPROM 저장 복구와 달무리 글꼴·메뉴 표시 수정을 포함합니다.

![나리키리 던전 2 프로젝트 식별 이미지](https://raw.githubusercontent.com/GimoXagros/narikiri2-save-compat/v0.9a/logo.png)

`logo.png`는 사용자가 저장소 식별용으로 제출하고 사용을 요청한 이미지입니다. 공식 로고나 원 게임 권리자의 승인·제휴를 뜻하지 않으며, 코드·문서의 MIT 라이선스와 글꼴의 Apache-2.0 라이선스가 이 이미지에 적용되지는 않습니다. 파일 정보와 권리 경계는 [RIGHTS.md](RIGHTS.md)에 기록합니다. 배포 ZIP의 이 문서도 저장소 이미지를 참조하며 로고 파일 자체는 포함하지 않습니다.

기본 이름은 **훌리오 / 캐로**입니다. 인물·코스튬 이름은 사용자가 제공한 나무위키 표를 기준으로 맞췄습니다. 대사에서도 **필리아, 훈다크르, 나리키리사**를 사용합니다. 표 안에서 충돌하는 표기는 인물 제목의 셀시우스, 리드, 스탄으로 통일했으며, 등장인물의 역할과 사건은 게임 원문을 보존했습니다.

## 적용

[v0.9a 릴리즈](https://github.com/GimoXagros/narikiri2-save-compat/releases/tag/v0.9a)의 `NARIKIRI2_AN9J_K_DALMOORI_v0.9a_FFR_PACKAGE.zip`을 풀고 Python 3.10 이상으로 실행합니다. 적용에는 추가 Python 패키지가 필요하지 않습니다.

```powershell
python apply_ffr_v09a.py "최초_FFR.gba" --output "NARIKIRI2_AN9J_K_DALMOORI_v0.9a.gba"
```

**최초 FFR 원본에 누적 패치 하나를 적용합니다.** v0.9나 다른 수정본에 덧붙이지 마십시오. 기존 출력 파일은 덮어쓰지 않습니다.

| 파일 | 바이트 | SHA-256 |
| --- | ---: | --- |
| FFR 입력 | 12,582,912 | `f94cb5a128c8a98e6e18e6a0598ebf9b266f54da0750367af8defac3eb2df7d4` |
| v0.9a 결과 | 13,041,664 | `faa2f0ebe1f7bbd9f4a7e1d38b7d35ca2349bfed1d8c2a5d8ae45feb0f7631f6` |
| FFR BPS | 501,338 | `9289ff85f946fa661c17dee9a9cb6afcd91278caf1af23590e59964ad461810a` |

## 변경과 확인

- 대사·설명 등 중복을 제외한 8,038개 문자열을 개별 대조하고, 5,186개를 교정했습니다. 이름, 띄어쓰기, 맞춤법과 표현을 점검했으며 수치·제어 코드를 검사합니다.
- 스펙터클즈와 인스펙트 아이 사용 시 적 이름·공격 속성·강점·약점 표시를 수정했습니다.
- 아이템 설명 9곳의 표시 폭 초과를 수정하고, 두 줄 설명창의 길이 검사를 추가했습니다.
- 새 게임, 혼합 이름, 기존 8 KiB 저장의 재저장·재실행, 중단 저장의 1회 재개와 전투 복귀를 mGBA에서 확인했습니다.
- 아이템 156종, 코스튬 도감 200종, 몬스터 도감 142종, 인물 도감 22명과 코스튬별 기술 이름 224종을 시험 상태에서 표시 확인했습니다.

도감·아이템의 일괄 표시 검사와 적 정보창의 사용 준비에는 별도 RAM 시험 상태를 사용했습니다. 자연 해금이나 전편 플레이 완료를 뜻하지 않습니다. [검증 범위](VERIFICATION.md)와 [변경 내역](RELEASE_NOTES.md)을 확인하십시오.

## 세이브

기존 Candidate A/v0.9의 **8 KiB 게임 내 저장**을 사용할 수 있습니다. 원본 저장을 복사해 보관하고 실행기에 맞춰 새 ROM과 저장 파일의 기본 이름·위치를 맞추십시오. 이전 ROM의 savestate 대신 게임의 이어하기를 사용하십시오. 수정 전 VBA-M의 32 KiB 저장은 별도 형식 판정이 필요합니다. 적용 도구는 저장 파일을 변경하지 않습니다.

직접 정한 이름은 유지됩니다. 기본 이름 변경은 새 게임부터 적용됩니다.

## 공개 범위

개발·이슈·배포의 기준 저장소는 현재 저장소입니다. 2026-09-07 저장소 통합은 v0.9a 게임 내용이나 기존 다운로드를 변경하지 않습니다. [통합 기록](MIGRATION.md)에 이전 대조·독립 재현·보관 상태를 기록합니다.

공개 파일은 패치·적용 도구·문서입니다. ROM·세이브·BIOS·전체 추출 대본은 포함하지 않습니다. [권리 고지](RIGHTS.md), [글꼴 출처](THIRD_PARTY_NOTICES.md)를 함께 확인하십시오.

v0.9a는 공개 검증판이며, 최종 ROM의 실기 시험과 장시간 전체 진행 검증은 v1.0 조건으로 남아 있습니다. 달무리 영문·숫자는 원래 4픽셀 폭을 유지하므로 기존 8픽셀 셀 안의 간격이 달라 보입니다.
