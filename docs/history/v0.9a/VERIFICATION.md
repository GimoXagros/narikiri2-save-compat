## 최종 ROM에서 실행

환경은 mGBA `0.11-219-e31759b`, 코어 SHA-256 `0d3177c927d791fef897f735d88db3646f7932d02054af108619c6df4e1597f1`입니다.

- 새 게임의 훌리오/캐로로 실제 저장 완료 화면을 확인하고, 프로그램을 두 차례 새로 실행해 이어하기·재저장과 이름 보존을 확인했습니다.
- 6칸 혼합 이름을 정상 입력 화면에서 만들고, 저장·두 차례 재실행 후 이름 바이트가 유지되는지 확인했습니다.
- 기존 8 KiB 저장의 재저장·재실행, 중단 저장의 재개와 재개 후 중단 선택 소멸을 확인했습니다.
- 첫 숲 전투의 주문·메뉴·승리·필드 복귀 경로를 RAM 변경 없이 실행했습니다.
- 스펙터클즈와 인스펙트 아이를 실제 사용하여 정보창을 열고, 닫기와 전투 복귀를 확인했습니다. 아이템 보유량과 필리아 코스튬의 기술 사용 준비만 독립된 RAM 시험 상태로 설정했습니다.
- 아이템 156종을 157번 선택하며 소형 글리프와 투명 배경을 포함한 기본 글꼴 8,192바이트가 정상인지 검사했습니다. 수정한 설명 9곳은 실제 화면으로 다시 확인했습니다.
- 코스튬 도감 200종, 몬스터 도감 142종, 인물 도감 22명의 목록·상세 진입과 복귀를 시험했습니다. 인물 소개 110화면의 표시와 페이지 넘김을 확인했습니다.
- 코스튬 페이지의 기술 이름 224종을 픽셀 대조했습니다. 별도로 231개의 0번 이외 기술 레코드를 기술 설정창에 표시해 설명·소비 TP·속성의 두 줄 표시를 확인했습니다. 0번은 미사용 ‘없음’ 레코드이며 정적 검사 대상입니다.

마지막 레이시스 표기 변경 후 전체 주요 실행 경로를 최종 ROM으로 다시 실행했습니다. 앞서 확인한 2,131개 원본 크기 화면이 동일했으며, 바뀐 도감 소개 2화면은 새로 확인했습니다. 기술 설명 231화면도 이전에 개별 확인한 화면과 모두 바이트가 동일합니다.

도감 해금 비트와 기술·아이템 준비에 사용한 시험 상태는 자연 해금, 전투에서의 모든 기술 사용 가능성 또는 저장 호환 증거로 세지 않았습니다. 저장·이름·일반 전투 검사는 이와 분리했습니다.

## 공개 검증판의 한계

전체 대본 대조가 모든 분기의 실제 플레이 완료를 뜻하지 않습니다. 최종 ROM의 실기 시험과 장시간 전체 진행은 v1.0 조건입니다. 기존 실기 성공 기록을 최종 v0.9a의 실기 검증으로 대체하지 않습니다.

직접 설정한 기존 이름은 유지합니다. 기본 이름 변경은 새 게임부터 적용되며, 이전 버전의 savestate 대신 게임 내 8 KiB 저장을 사용합니다. 달무리 영문·숫자의 원래 4픽셀 폭은 기존 8픽셀 셀 안에서 간격이 달라 보일 수 있습니다.

[v0.9의 역사적 검증 기록](docs/history/v0.9/VERIFICATION.md)은 별도로 보존합니다.
