# v0.5 — 실기 저장 호환 복구 도구 (소스 전용)

한글패치가 아닙니다. 기존 K_FFR 한글판의 번역은 그대로 두고 저장 관련 79바이트만 복원합니다.

공개 구성에는 Python 도구·테스트·설명서만 있습니다. ROM, 세이브, 번역문, 폰트, 원본 실행 코드 바이트와 BPS/IPS는 포함하지 않습니다. **최초 K_FFR 한글판과 일본어 원본을 모두 로컬에서 준비해야 합니다.**

Python 3.10 이상에서:

```powershell
python restore.py --korean "최초_K_FFR.gba" --japanese "일본어_원본.gba" --output "NARIKIRI2_SAVE_COMPAT_v0.5.gba"
```

지원 입력의 정확한 크기·해시와 세이브 주의사항은 README.md를 확인하십시오. 기존 파일은 덮어쓰지 않습니다. 복구 결과 SHA-256:

`9c7a8ae87c303a16c71bd164e7409a5aaabf01bd3246fa9e700931eed6179d4f`

기존 Candidate A/v0.5와 동일한 결과이므로 이미 해당 ROM을 사용한다면 다시 처리할 필요가 없습니다. 기존 저장·로드 검증의 범위는 VERIFICATION.md에 명시했습니다. 모든 기기와 전체 게임의 무결함을 보장하지 않습니다.

MIT 라이선스는 새 도구·문서에만 적용됩니다. 원 게임·기존 한글패치와 생성 ROM의 제3자 내용은 적용 대상이 아닙니다.
