# BETA2 → BETA3(071102) 이식 기록

사용자는 첨부된 BETA3(071102)를 기준으로 확정했습니다. 명령문에 적힌 271102는 파일 이름을 바꾸거나 다른 버전을 선택하는 근거로 사용하지 않았습니다. 소스 프로필은 config/source_profiles.json, 전체 결과 해시는 verification/v0.9b.json에 있습니다.

BETA2와 BETA3의 공통 길이에서 84,776바이트 / 7,301개 연속 차이 구간을 확인했습니다. BETA3에서 제거된 0x980000..0xC00000은 BETA2의 0 채움 영역입니다. 단순히 BETA2의 전체 수정 ROM을 BETA3 위에 복사하지 않았습니다.

## 기능별 처리

| 기존 작업 | BETA3 처리 |
| --- | --- |
| EEPROM 저장 복구 | BETA3가 이미 일본어 구현을 보유. 저장 코드 전체를 보존 |
| 달무리 글꼴·고유명사·메뉴 | 기존 소스 바이트와 쓰기 범위를 확인한 뒤 이식 |
| 노란 배경 덧칠·VRAM 투명도 | 기존 수리 이식 후 모든 아이템 화면의 글꼴 바이트와 픽셀 확인 |
| 전투 이름·적 정보창 | 훅·리소스 일치를 확인하고 실제 아이템/기술 사용 회귀 시험 |
| v0.9a 대사·문법·명칭 교정 | 고정 원본을 재현하고 BETA3의 8,946개 참조에 다시 연결 |
| BETA3 대사 변경 2건 | 원문 감사·보상 의미를 대조한 개별 교정 |
| BETA3 LIGHT/라이트닝 차이 | ARTE_058/211의 BETA3 원문을 확인해 라이트닝 유지 |
| 추가 일본어 대조 | 8,037개 실제 본문과 1,227개 짧은 이름 필드. 추가 285문장·16필드 교정 |
| 옷 교환 구조 | A4918을 08373760 테이블로 복원. 기존 D00549는 문자열 오분류 |

소리·원래 큰 글꼴 구간 0xAC3F4..0x2B2CAC와 EEPROM 구간 0xA601C..0xA6800은 BETA3와 정확히 같습니다. 전송 계획 밖의 BETA3 바이트를 보존하고, 새 번역·글꼴 데이터는 검증한 확장 영역에 둡니다.

## 교정 자료와 예외

translation/v09b_beta3_decisions.json은 바뀐 대사 2건의 양쪽 원문 해시와 채택 문구를 기록합니다. translation/v09b_japanese_review.json은 일본어 참조·변경 전 한국어 해시로 묶은 285건, translation/v09b_compact_review.json은 짧은 이름 16필드를 기록합니다. 이전 v0.9a 자료는 역사적 재현을 위해 그대로 유지합니다.

일반 CP932에서 키릴 문자처럼 읽힌 8441..8447은 원본 게임의 사용자 정의 한자입니다. 원본 비트맵과 기술 이름을 대조해 해결했습니다. D02958과 아이템 085의 꽃 이름은 일본어 내부 철자가 서로 달라 기존 아이템명 도에니스꽃으로 통일했습니다. SELECT_JOB의 개발용 이름을 공개 코스튬 이름보다 우선하지 않았습니다.

옷 교환 A4918은 실행 코드가 두 포인터를 읽는 구조입니다. 이전에는 저장 문장으로 잘못 옮겨졌으며 이를 본문 D00549로 분류한 것도 잘못이었습니다. 현재 0x373760/64의 실제 한국어 안내 D05660/D05661을 사용합니다. 전체 본문 분모는 8,038 → 8,037로 바로잡았습니다. 실제 두 기기의 교환 완료는 별도 시험 대상입니다.

v0.5 릴리즈는 초안으로 전환해 배포 중단하고 태그·이력·백업을 보존합니다. 자세한 이유는 V05_RETIREMENT.md에 기록합니다. v0.9와 v0.9a 태그 및 기존 공개 파일은 변경하지 않습니다.
